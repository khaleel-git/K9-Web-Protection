# BlockerFlow lists: licence terms

These are the licence terms that travel with the BlockerFlow data K9 redistributes. The data comes
from the public repo [khaleel-git/blockerflow-lists](https://github.com/khaleel-git/blockerflow-lists)
at the version pinned in `lists/blockerflow-lists.version`.

| Data in K9 | Licence | Text |
|---|---|---|
| `lists/categories/pornography/domains.txt` | GPL-3.0 | [LICENSE](LICENSE) |
| `lists/categories/proxy-avoidance/domains.txt` (BlockerFlow's web-proxy list) | CC BY-SA 4.0 | [CC-BY-SA-4.0.txt](CC-BY-SA-4.0.txt) |

The same data, as embedded in both apps' `domains.json`
(`mac/app/internal/database/` and `windows/app/internal/database/`), is under the same terms.

[NOTICE](NOTICE) is BlockerFlow's notice, copied unchanged from the upstream repo. It names each
source of the lists, its licence and the copyright notices that must stay with copies. The three
files here are byte-for-byte copies of the upstream `LICENSE`, `LICENSES/CC-BY-SA-4.0.txt` and
`NOTICE`.
